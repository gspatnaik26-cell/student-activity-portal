Student Activity Management Portal
Project Overview

The Student Activity Management Portal is a web-based application developed using HTML5 and CSS3. It allows university students to view upcoming events, explore university activities and register for different events.

The webpage is designed using semantic HTML elements and follows basic web accessibility principles.

Objectives
To develop a webpage using HTML5 semantic elements.
To display upcoming university events.
To provide information about university activities.
To create an accessible student registration form.
To implement responsive webpage styling.
To understand browser metadata and accessibility.
To use Git for version control.
